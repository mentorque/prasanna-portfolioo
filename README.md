# Portfolio Template — Modern (Animated)

Animated portfolio with profile card, scroll-stack experience, skills, certificates, and contact panel.

Works for any role — replace all placeholder text and assets with your own content.

## Customize

| What | Where |
|------|-------|
| Name, title, bio, contact | `src/components/sections/` |
| Profile photo | `public/placeholder.svg` |
| Certificate PDFs | `public/certificates/` |

## Run locally

```sh
npm i
npm run dev
```
